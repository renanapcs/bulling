# 📄 Cartilha de Conscientização sobre Cyberbullying

## 🎯 Sobre o Projeto

Esta cartilha foi desenvolvida para conscientizar sobre o cyberbullying, fornecendo orientações práticas para escolas, pais e estudantes sobre como prevenir e combater essa forma de violência digital.

## 🖨️ Como Gerar o PDF da Cartilha

### Método 1: Através do Site (Recomendado)
1. Acesse o `index.html` no navegador
2. Clique no botão **"📄 Baixar Cartilha em PDF"**
3. Uma nova aba será aberta com a versão para impressão
4. Use **Ctrl+P** (ou Cmd+P no Mac)
5. Escolha **"Salvar como PDF"** como destino
6. Configure para página **A4**
7. Clique em **"Salvar"**

### Método 2: Acesso Direto
1. Abra diretamente o arquivo `cartilha-impressao.html`
2. Use **Ctrl+P** para imprimir
3. Escolha **"Salvar como PDF"**
4. Configure para página **A4**

## 📋 Conteúdo da Cartilha

A cartilha contém **8 páginas** com:

1. **Capa** - Apresentação e introdução
2. **Definição** - O que é cyberbullying
3. **Papel da Escola** - 7 responsabilidades das instituições
4. **Papel dos Pais** - 6 orientações para famílias
5. **Consequências** - Impactos psicológicos e sociais
6. **Aspectos Legais** - Crimes relacionados e legislação
7. **Lei 14.811/2024** - Marco legal atualizado
8. **Mensagem Final** - Chamada para respeito e inclusão
9. **Informações Úteis** - Canais de denúncia e recursos
